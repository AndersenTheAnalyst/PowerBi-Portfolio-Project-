# Data Professionals Survey Analysis | Power BI

## 📌 Project Overview

This project analyzes a survey of data professionals using Power BI to uncover insights into their careers, salaries, job satisfaction, programming language preferences, and industry trends.

The project began with **data cleaning and transformation** to ensure the dataset was consistent, accurate, and suitable for analysis. After cleaning, the data was used to create an interactive Power BI dashboard for effective visualization and insight generation.

## 🎯 Project Objectives

- Clean and prepare raw survey data for analysis.
- Transform inconsistent data into a usable format.
- Analyze salary trends across different data-related job roles.
- Explore programming language preferences among data professionals.
- Examine job satisfaction and work-life balance.
- Build an interactive dashboard to communicate key findings.

## 🛠️ Tools Used

- **Power BI** — Data visualization and dashboard development.
- **Power Query** — Data cleaning and transformation.
- **DAX** — Measures and calculations, where applicable.

## 🧹 Project Workflow

### 1. Data Cleaning and Transformation

Before creating visualizations, the raw survey dataset was cleaned and prepared using Power Query.

The process focused on improving data quality by addressing inconsistencies, handling missing or irrelevant values where necessary, and transforming columns into suitable formats for analysis.

### 2. Data Analysis

After cleaning, the dataset was explored to identify patterns and trends relating to salaries, job roles, programming language preferences, and job satisfaction among data professionals.

### 3. Dashboard Development

An interactive dashboard was created in Power BI to present the survey findings through charts, graphs, and other visual elements, making the results easier to understand and explore.

## 📊 Key Areas of Analysis

- **Job Roles:** Distribution of professionals across different data-related careers.
- **Salary Analysis:** Salary differences across job titles.
- **Programming Languages:** Most popular programming languages among respondents.
- **Job Satisfaction:** Respondents' satisfaction with salary and work-life balance.
- **Industry Insights:** Trends and patterns in the data profession.

## 💡 Key Skills Demonstrated

- Data cleaning and preprocessing
- Power Query and data transformation
- Data visualization
- Dashboard design and development
- Exploratory data analysis
- Business intelligence and insight communication

## ✅ Project Outcome

The project demonstrates the importance of cleaning data before visualization and analysis. By transforming raw survey responses into a structured dataset and building an interactive dashboard, the project showcases how Power BI can turn data into meaningful insights that support better understanding and decision-making.
